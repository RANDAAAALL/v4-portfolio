# Open Sans

Open Sans variable font, obtained from the official Google Fonts repository:
https://github.com/googlefonts/opensans/tree/main/fonts/variable

Original file: `OpenSans[wdth,wght].ttf` (downloaded September 10, 2026).
The font is distributed under the SIL Open Font License, included in `OFL.txt`.
It is served locally through Next.js and does not require a third-party font request.
